Angular pages inside the conversation

An MCP App is a small web page that a chat host such as Claude shows when the model calls a tool. ngx-mcp-apps lets you write it as a normal Angular application, and builds it into the single HTML file that hosts expect. 

ng add ngx-mcp-apps-builder
Get started

Below is a real application, running against a host that lives in this page. Add an item, switch the theme, go fullscreen: the right column shows each message as it crosses.

Signals, not listeners

The connection, the tool result, the host theme and the display mode are signals. A template reads them like any other state.

About 5 kB, nothing else

The app side of the protocol is implemented in the library: under 5 kB gzipped, with no runtime dependencies.

One file out of ng build

The builder runs Angular's own application builder, then inlines scripts, styles, fonts and images of the CSS. If something cannot fit in one file, the build fails and says what.

Angular 18 to 22

Each major is checked with a new application: installed, built, opened in a browser.
